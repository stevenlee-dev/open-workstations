# 设计说明

浏览器端使用 Vue，API 使用 Express，数据和附件存储在一个 SQLite 数据库中。小规模部署只需一个 Node 进程和反向代理。前端只负责展示与收集输入；身份、日期和审批冲突都由服务端重新判断。

公开接口只返回空间、工位、当日占用状态及待审核数量，不返回申请人姓名或材料。申请详情只有本人和管理员可以读取。管理员角色是通用的 `manager`，可以部署多个管理员账号；项目不预设学校、老师或社团职位。

申请状态从 `pending` 进入 `approved`、`rejected` 或 `withdrawn`；已批准申请到期后进入 `expired`。多个人可同时申请同一工位。批准时在 SQLite `BEGIN IMMEDIATE` 事务内检查时间段重叠，避免并发批准两份互相冲突的申请。管理员提交的 `version` 用于阻止过期页面覆盖新结果。审批与撤回会记录在事件表中。

登录采用带 `HttpOnly`、`SameSite=Strict` Cookie 的服务器端会话。写请求验证来源、请求标识和会话 CSRF 令牌。密码使用 scrypt 哈希。附件始终以下载方式返回，禁止浏览器嗅探内容类型。管理员账号由命令行创建，密码从临时环境变量读取。

当前设计有意保持边界清楚：没有短信/邮件网关、没有自动续期、没有在线地图编辑器，也没有对附件做病毒扫描。对大规模用户量或合规要求较高的部署，应引入身份提供方、对象存储、作业队列和独立审计策略。
